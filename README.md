# 마지막 방 — 특수청소부의 기록

고인이 남긴 방을 치우고, 남겨진 물건으로 마지막 이야기를 듣는 1인칭 추리 게임입니다.

방 한 칸이 이야기 하나인 옴니버스 구성이고, 각 장은 세 단계로 진행됩니다.

1. **현장 정리**: 손전등 하나에 의지해 방에 들어갑니다. 얼룩에 소독약을 뿌리고 문질러 닦고, 물건마다 유족에게 돌려줄지 버릴지 정합니다.
2. **유품 조사**: 작업실로 가져온 유품을 돌려 보며 숨은 단서를 찾습니다. 휴대폰 잠금, 숫자 자물쇠, 이중 바닥, UV 라이트로만 보이는 흔적이 있습니다.
3. **사건 재구성**: 모은 단서로 고인의 진짜 사망 원인과 사연을 밝힙니다. 마지막에는 고인이 끝내 전하지 못한 편지를 유족에게 전할지, 태워 없앨지 정합니다.

| 2장 | 반지하 B01호 | 겨울 통장 |

| 4장 | 공단 원룸 202호 | 편도 |

> 죽음, 고독사, 과로, 약물 오남용 같은 무거운 이야기를 다룹니다. 게임 속 인물과 사건은 모두 지어낸 이야기입니다.

## 내려받기

**https://eunyool10.github.io/LastRoom/** — 접속한 기기에 맞는 파일과 받는 방법을 보여 줍니다.

| 기기 | 받는 것 | 단계 |
| --- | --- | --- |
| Windows | 설치 파일 `LastRoom-Setup-1.3.5.exe` | 정식 1.3.5 |
| Android | APK `LastRoom-1.3.5-android.apk` (Android 7.0 이상) | 테스트 베타 1.3.5 |
| Mac | 앱 압축 파일 `LastRoom-1.3.5-mac.zip` (Apple 칩 · Intel) | 테스트 베타 1.3.5 |
| iPhone · iPad · 브라우저 | [웹 버전](https://eunyool10.github.io/LastRoom/play/) — 설치 없이 실행, 홈 화면에 추가 가능 | 테스트 베타 1.3.5 |

1.2.0부터는 게임을 켤 때 새 버전이 있는지 확인합니다. Windows는 게임 안에서 **지금 업데이트**를 누르면 새 설치 파일을 받아 덮어 설치하고 다시 켭니다. Android는 새 APK를 받아 열면 기존 앱 위에 업데이트됩니다. 웹 버전은 늘 새 버전으로 열립니다. 저장 기록은 그대로 남습니다.

게임 안 업데이트는 이 저장소의 릴리스 파일만 받고, 받은 설치 파일이 원본과 같은지 확인값(SHA-256)으로 확인한 다음에만 설치합니다. 직접 받은 파일도 내려받기 페이지의 **파일 확인값**과 비교할 수 있습니다(Windows PowerShell: `Get-FileHash 파일이름`).

## 설치 방법 (Windows)

1. [Releases](../../releases/latest)에서 `LastRoom-Setup-1.3.5.exe`를 내려받아 실행합니다.
2. 설치 화면에서 **이용 안내**를 읽고 **동의함**을 누릅니다.
3. 설치 위치를 확인하고 **설치**를 누릅니다.
4. 바탕 화면이나 시작 메뉴의 **마지막 방**으로 실행합니다.

지울 때는 Windows 설정의 **앱** 목록이나 시작 메뉴의 **마지막 방 제거**를 쓰면 됩니다.

### "Windows의 PC 보호" 창이 뜨면

코드 서명이 없는 개인 제작 프로그램이라, 처음 실행할 때 Windows가 확인 창을 띄웁니다.

1. 창에서 **추가 정보**를 누릅니다.
2. 아래에 나타나는 **실행** 버튼을 누릅니다.

## 조작법

| 키 | 동작 |
| --- | --- |
| W A S D / 마우스 | 이동 / 둘러보기 |
| 1 · 2 · 3, 휠 | 손 · 소독 분무기 · 스크러버 |
| 왼쪽 버튼 누르고 있기 | 도구 사용 (스크러버는 누른 채 마우스를 움직여 문지르기) |
| E 또는 왼쪽 클릭 | 집어 보기 · 조사 / 들고 있을 때는 보관함에 넣기 / 서랍 · 문 열고 닫기 |
| Q | 폐기 |
| X 또는 오른쪽 클릭 | 내려놓기 |
| F | 손전등 |
| I 또는 Tab | 보관함 (넣거나 버린 물건 보기 · 다시 꺼내기) |
| Ctrl 누르고 있기 | 숙이기 (웹 버전은 C, 설정에서 누를 때마다 바뀌게 할 수 있음) |
| U / H / R | (유품 조사) UV 라이트 / 단서 위치 / 정면 보기 |
| Esc / F11 | 멈춤 / 전체 화면 |

휴대폰 · 태블릿(베타)에서는 왼쪽 화면을 끌어 걷고 오른쪽 화면을 끌어 둘러봅니다. 도구, 집기, 보관 · 폐기 · 내려놓기는 오른쪽 아래 버튼으로, 멈춤은 왼쪽 위 버튼으로 합니다. 유품 조사에서는 두 손가락으로 확대합니다.

## 설정과 기록

설정은 화면 · 소리 · 조작 · 기록 · 정보 다섯 쪽으로 나뉩니다. 밝기 · 시야 · 화질 · 깜빡임 줄이기, 효과음 · 주변 소리 크기, 감도 · 상하 반전 · 숙이기 방식을 바꿀 수 있습니다. **기록 → 백업 코드 만들기**로 끝낸 장 · 등급 · 설정을 글자 코드로 옮겨 두면, 기기를 바꾸거나 기록이 지워졌을 때 타이틀 화면의 설정에서 되살릴 수 있습니다.
