# 마지막 방 — 특수청소부의 기록

고인이 남긴 방을 치우고, 남겨진 물건으로 마지막 이야기를 듣는 1인칭 추리 게임입니다.

방 한 칸이 이야기 하나인 옴니버스 구성이고, 각 장은 세 단계로 진행됩니다.

1. **현장 정리**: 손전등 하나에 의지해 방에 들어갑니다. 얼룩에 소독약을 뿌리고 문질러 닦고, 물건마다 유족에게 돌려줄지 버릴지 정합니다.
2. **유품 조사**: 작업실로 가져온 유품을 돌려 보며 숨은 단서를 찾습니다. 휴대폰 패턴, 숫자 자물쇠, 이중 바닥, UV 라이트로만 보이는 흔적이 있습니다.
3. **사건 재구성**: 모은 단서로 고인의 진짜 사망 원인과 사연을 밝힙니다. 마지막에는 고인이 끝내 전하지 못한 편지를 유족에게 전할지, 태워 없앨지 정합니다.

| 장 | 장소 | 제목 |
| --- | --- | --- |
| 1장 | 고시원 307호 | 합격 통보 |
| 2장 | 반지하 B01호 | 겨울 통장 |
| 3장 | 오피스텔 1203호 | 필터 |

> 죽음, 고독사, 약물 오남용 같은 무거운 이야기를 다룹니다.

## 플레이 방법 (Windows)

1. [Releases](../../releases/latest)에서 `LastRoom-windows.zip`을 내려받습니다.
2. 압축을 풀고 `LastRoom` 폴더 안의 `LastRoom.exe`를 실행합니다.

설치 과정은 없습니다. Windows가 "PC 보호" 창을 띄우면 **추가 정보 → 실행**을 누르세요.

## 조작법

| 키 | 동작 |
| --- | --- |
| W A S D / 마우스 | 이동 / 둘러보기 |
| 1 · 2 · 3, 휠 | 손 · 소독 분무기 · 스크러버 |
| 왼쪽 버튼 누르고 있기 | 도구 사용 (스크러버는 마우스를 움직여 문지르기) |
| E / Q / X | 집어 보기 · 보관함에 넣기 / 폐기 / 내려놓기 |
| F | 손전등 |
| U / H / R | (유품 조사) UV 라이트 / 단서 위치 / 정면 보기 |
| Esc / F11 | 멈춤 / 전체 화면 |
